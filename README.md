# pulsar

Reads signals from someone's career (resume, stories, target roles) and detects opportunities they might not otherwise find.

## Getting Started

This is a [Next.js](https://nextjs.org) app. Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
